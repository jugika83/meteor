# 🌠 유성현황

**https://jugika83.github.io/meteor/**

오늘 밤 별과 유성을 **어디서 몇 시에** 보면 되는지 알려주는 한 장짜리 현황판.
서울·대전·대구·부산·제주 중에서 고르면 그 지역 기준으로 전부 다시 계산된다.

## 무엇을 보여주나

| | 내용 | 어디서 온 값인가 | 신뢰도 |
|---|---|---|---|
| ① | **오늘 밤 하늘** — 장소별 구름·미세먼지·종합점수 | Open-Meteo 실시간 예보 | 일반 일기예보 수준 |
| ② | 일몰·천문박명·달, 유성우별 시간대별 예상 개수 | 프로그램이 직접 계산 | 높음 (±1~2분) |
| ③ | 어디로 가면 어두운가 — 전국 관측지 순위 | 시·군 인구·거리 기반 빛공해 **추정** | 순위는 신뢰, 절대값은 참고용 |
| ④ | 다음 유성우 달력 | IMO 공표 극대일 | 높음 |
| ⑤~⑧ | 최근 관측된 유성 세계지도·순위·밝은 유성 | Global Meteor Network 실측 | 높음 (단 2~3일 지연) |
| ⑨ | 지금 활동량(ZHR) 그래프 | GMN flux | 몇 시간 단위 갱신 |

예상 관측 개수는 IMO 표준식
`시간당 개수 = ZHR × sin(복사점 고도) ÷ r^(6.5−한계등급)` 으로 계산한다.

## 갱신

**매일 오후 5시 자동으로 갱신된다** (GitHub Actions, PC 꺼져 있어도 동작).
날씨는 방문자가 페이지를 열 때마다 실시간으로 새로 받아온다.

직접 갱신하려면:

```
사이트올리기.bat                                   # 만들고 인터넷 반영까지
유성현황.bat                                       # 내 PC에서 보기만
```

관측지 기본값은 `관측지.txt` 에서 바꾼다. (지금은 부산)

## 한계 — 정직하게

- **빛공해는 실측이 아니라 추정치다.** 전국 시·군 인구와 거리로 계산했다. 어디가 더 어두운지 순위는 믿을 만하지만, "한계등급 6.3" 같은 절대 수치는 ±0.5등급 오차를 봐야 한다.
- **GMN 유성 데이터는 2~3일 지연된다.** 여러 나라 카메라 관측을 대조해 궤도를 계산하기 때문이다. 초 단위 실시간이 필요하면 전파관측(RTL-SDR)이나 자체 카메라가 필요하다.
- **지형과 현장 조명은 반영하지 않는다.** 산이 시야를 가리거나 주차장 가로등이 있으면 계산과 다르다.
- 관측지 좌표는 대략값(±수 km)이라 지역 확인용이지 내비게이션용이 아니다.
