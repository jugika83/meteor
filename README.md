# 🌠 유성현황

오늘 밤 유성을 **어디서 몇 시에** 보면 되는지 알려주는 한 장짜리 현황판.
전 세계 아마추어 관측망 [Global Meteor Network](https://globalmeteornetwork.org/)의
공개 데이터(CC BY 4.0)를 받아서 만든다.

## 보는 곳

`docs/index.html` 이 그대로 웹사이트가 된다. (GitHub Pages)

## 다시 만들기

```
유성현황.bat                                   # 서울 기준
유성현황.bat --lat 35.18 --lon 129.075 --place 부산
사이트올리기.bat                                # 새로 만들고 인터넷에 반영까지
```

## 무엇이 들어 있나

| | 내용 | 어디서 왔나 |
|---|---|---|
| ① | 오늘 밤 관측 조건 + 시간대별 예상 개수 | 일몰·달·복사점 고도를 직접 계산 |
| ② | 어디로 가면 잘 보이나 (전국 관측지 순위) | 도시 인구·거리로 빛공해 추정 |
| ③ | 최근 관측된 유성 세계지도 | GMN 궤도 데이터 |
| ④~⑥ | 시간대별 검출량 / 유성우 순위 / 밝은 유성 | GMN 궤도 데이터 |
| ⑦ | 지금 활동량(ZHR) | GMN flux |

예상 관측 개수는 IMO 표준식
`시간당 개수 = ZHR × sin(복사점 고도) ÷ r^(6.5−한계등급)` 으로 계산한다.
구름과 지형은 반영하지 않으므로 순위 참고용.

## 한계

GMN 궤도 데이터는 여러 나라 카메라 관측을 대조해 계산하느라 **2~3일 지연**된다.
초 단위 실시간이 필요하면 전파관측(RTL-SDR)이나 자체 카메라 스테이션을 붙여야 한다.
